# Crossword Maker requirements

Platform: browser, statically hosted on GitHub Pages. Status: implemented; verification references below.

| ID     | Behavior and acceptance criteria                                                                                                                                                                                                                                                                                                                                                            | Verification                                                      |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| CW-001 | Teachers enter paired clues and answers. Answers are A–Z only; ASCII lowercase converts to uppercase. Invalid answers, duplicate answers, and missing clues are flagged. Bulk entry appends tab-separated answer/clue rows. Empty draft rows are ignored.                                                                                                                                   | generator.test.js validation; app.spec.js bulk and invalid input  |
| CW-002 | Generate a connected open grid using only supplied valid answers, across and down, with matching intersections and no unintended adjacent letter runs or parallel overlaps. Number starts in reading order; shared starts share a number. List unplaced answers and identify disconnected letter groups. Never silently omit entries from export.                                           | generator.test.js geometry, coverage, disconnected groups         |
| CW-003 | Regenerate automatically after answer changes and after an entry becomes eligible. Keep startup controls disabled with a visible loading status until the workspace is ready. Debounce typing, search off the main thread, show a visible activity indicator and best-so-far preview, and cancel stale searches when editing or switching puzzles. Regenerate explicitly tries new layouts. | app.spec.js generation and clue completion; worker implementation |
| CW-004 | Title, name, class period, date and clue answer lines are individually optional, all off initially. When enabled, class period is left, name right, date alongside, title centered. Last-used option values and paper size become defaults for newly created puzzles without changing other existing puzzles.                                                                               | app.spec.js preferences and new puzzle                            |
| CW-005 | Create, name, switch, duplicate and delete puzzles. Deletion requires confirmation, cancellation keeps the puzzle. Autosave puzzles and exact generated arrangements in IndexedDB, restoring them on reload. Display storage failures. Appearance is light/dark/auto, initially auto, and persists.                                                                                         | app.spec.js persistence, duplicate/delete workflow, appearance    |
| CW-006 | One-page worksheet: optional header, numbered grid, Across and Down clue columns. Letter default; Legal, A4 and A5 supported. Preview and output use white paper and black text under every editor theme. Fit type and grid within readable thresholds; if impossible, show a warning and block output without removing content.                                                            | app.spec.js preview, PDF; shared renderer; manual page review     |
| CW-007 | Preview, download PDF or print worksheet, answer key, or both. The key uses identical grid geometry with answers filled in. Both outputs are individually single pages. PDF and preview share page geometry.                                                                                                                                                                                | app.spec.js key, two-page PDF download; manual print review       |
| CW-008 | Export all puzzles to versioned JSON. Import validates data, adds new puzzle records, retains valid arrangements and never overwrites existing records. Reject malformed/oversized backups with feedback. Puzzle data remains browser-local.                                                                                                                                                | generator.test.js backup validation; app.spec.js round trip       |
| CW-009 | Public BSD 3-Clause source repository. Published stable releases trigger a tested build and GitHub Pages deployment of that release tag. Pushes run CI without publishing.                                                                                                                                                                                                                  | .github/workflows/ci.yml and release.yml; first release run       |

Manual QA: review desktop and narrow mobile viewports, light/dark/system, print preview at each paper size, and a worksheet too large to fit. Browser storage is per origin/device; backup is the portability mechanism.

CW-010 — The editor uses an unbranded, compact utility interface with neutral gray backgrounds and blue accents in both appearances. Answer and clue inputs occupy adjacent table columns, with automatic clue row sizing. On desktop, the complete worksheet preview and output controls fit the available viewport; the editor scrolls independently. Mobile stacks the editor and preview. Verification: app.spec.js desktop sizing, table editing, themes, mobile overflow, and existing PDF/print workflow checks.
