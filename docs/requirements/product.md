# Crossword Maker requirements

Platform: browser, statically hosted on GitHub Pages. Status: implemented; verification references below.

| ID     | Behavior and acceptance criteria                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Verification                                                      |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| CW-001 | Teachers enter paired clues and answers. Answers are A–Z only; ASCII lowercase converts to uppercase. Invalid answers, duplicate answers, and missing clues are flagged. Bulk entry appends answer/clue rows separated by a comma, a tab, or one or more spaces. Lowercase and mixed-case answers convert to uppercase. The first comma separates the answer from the clue; subsequent clue commas are preserved. Standard quoted fields and doubled quote escapes are accepted. Empty draft rows are ignored. | generator.test.js validation; app.spec.js bulk and invalid input  |
| CW-002 | Generate a connected grid using only supplied valid answers, across and down, with matching intersections and no unintended adjacent letter runs or parallel overlaps. Number starts in reading order; shared starts share a number. If unused cells are no more than 20% of the grid's bounding rectangle, render them as black blocks; otherwise preserve the open-grid style. List unplaced answers and identify disconnected letter groups. Never silently omit entries from export. | generator.test.js geometry, coverage, disconnected groups         |
| CW-003 | Regenerate automatically after answer changes and after an entry becomes eligible. Keep startup controls disabled with a visible loading status until the workspace is ready. Debounce typing, search off the main thread, show a visible activity indicator and best-so-far preview, and cancel stale searches when editing or switching puzzles. Regenerate explicitly tries new layouts.                                                                                                                    | app.spec.js generation and clue completion; worker implementation |
| CW-004 | Title, name, class period, date and clue answer lines are individually optional, all off initially. When enabled, class period is left, name right, date alongside, title centered. Last-used option values and paper size become defaults for newly created puzzles without changing other existing puzzles.                                                                                                                                                                                                  | app.spec.js preferences and new puzzle                            |
| CW-005 | Create, name, switch, duplicate and delete puzzles. Deletion requires confirmation, cancellation keeps the puzzle. Autosave puzzles and exact generated arrangements in IndexedDB, restoring them on reload. Display storage failures. Appearance is light/dark/auto, initially auto, and persists.                                                                                                                                                                                                            | app.spec.js persistence, duplicate/delete workflow, appearance    |
| CW-006 | One-page worksheet: optional header, numbered grid, and Across/Down clues in two columns by default. When needed to keep grid cells at least 19 pt, distribute clues across three or four columns, showing each direction heading once; if that is still insufficient, use the arrangement that gives the grid the most room. Letter default; Legal, A4 and A5 supported. Preview and output use white paper and black text under every editor theme. If the grid still cannot fit readably, show a warning and block output without removing content. | app.spec.js preview, PDF; shared renderer; manual page review     |
| CW-007 | Download PDF and Print output only the currently selected preview (worksheet or answer key), without a separate output selector. The key uses identical grid geometry with answers filled in. Each output is a single page. PDF and preview share page geometry.                                                                                                                                                                                                                                               | app.spec.js key, single-page PDF download; manual print review    |
| CW-008 | Export all puzzles to versioned JSON. Import validates data, adds new puzzle records, retains valid arrangements and never overwrites existing records. Reject malformed/oversized backups with feedback. Puzzle data remains browser-local.                                                                                                                                                                                                                                                                   | generator.test.js backup validation; app.spec.js round trip       |
| CW-009 | Public BSD 3-Clause source repository. Published stable releases trigger a tested build and GitHub Pages deployment of that release tag. Pushes run CI without publishing.                                                                                                                                                                                                                                                                                                                                     | .github/workflows/ci.yml and release.yml; first release run       |

Manual QA: review desktop and narrow mobile viewports, light/dark/system, print preview at each paper size, and a worksheet too large to fit. Browser storage is per origin/device; backup is the portability mechanism.

CW-010 — The editor uses an unbranded, compact utility interface with neutral gray backgrounds and blue accents in both appearances. Answer and clue inputs occupy adjacent table columns, with automatic clue row sizing. On desktop, the complete worksheet preview and output controls fit the available viewport; the editor scrolls independently. Mobile stacks the editor and preview. Verification: app.spec.js desktop sizing, table editing, themes, mobile overflow, and existing PDF/print workflow checks.

The desktop preview pane reserves only the width required by its controls or the widest supported page fitted to the available height, whichever is larger. Remaining horizontal space goes to the editor. Changing paper sizes keeps the divider stable; narrower viewports retain the minimum editor width and mobile stacking.

Loading the example requires confirmation whenever the current puzzle has a title, custom name, answer, or clue. Cancel and Escape preserve the current view. Confirming opens a new sample while retaining the existing puzzle. Row removal uses an × button with an accessible name.

Removing any row containing an answer or clue requires confirmation; empty rows remove immediately. Each row has a selection checkbox, with select-all and a selected-count bulk removal action. Bulk removal uses one confirmation if any selected row contains data. Cancel/Escape preserve data and selection, and row selections clear when switching puzzles.

The preview frame hugs the scaled paper vertically, keeping print/download actions directly below it when pane width limits page size. It does not expand to fill unused vertical space.

Clue answer lines span the available clue-column width after the number indent and provide extra vertical handwriting space below the clue. Preview, print, and PDF use the same spacing.

Clue text and wrapped continuation lines align at one fixed indent based on the widest clue number; numbers occupy a separate right-aligned column. Across/Down headings use Noto Sans Bold. Grid numbers are enlarged for readability, and answer lines provide extra handwriting room above the baseline.

Fully checked word lists also use a bounded constraint search that permits adjacent partial words, constrains word ends, and completes both Across and Down membership for every letter. Validate final geometry independently of insertion order when restoring or importing. Oversized layouts remain visible as a reduced preview with a page-fit warning; unreadable print/PDF output remains blocked.

Import opens a native file chooser directly from an accessible file input, including Safari, and shows importing, success, or failure feedback. Failed imports keep existing puzzles intact; the chooser remains usable for a retry or the same file again.
